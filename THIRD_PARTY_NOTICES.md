# Компоненты

Langg использует Sparkle 2.10.0 для обновлений. Sparkle распространяется по лицензии MIT с дополнительными уведомлениями о включённых компонентах.

Полный текст лицензий находится в [официальном репозитории Sparkle](https://github.com/sparkle-project/Sparkle/blob/2.10.0/LICENSE) и включён в Resources/Sparkle-LICENSE.txt внутри приложения. Уведомления сохраняются при упаковке.

## Установка

1. Скачайте файл `Langg-…-macOS.dmg` со [страницы последнего релиза](https://github.com/frlvv/Langg/releases/latest).
2. Откройте образ и перетащите Langg в папку Applications.
3. Запустите Langg и следуйте подсказкам по разрешениям. Добавьте раскладки «Русская» и «ABC» или «США», если их ещё нет.

При первом запуске macOS может запросить подтверждение в разделе **Системные настройки → Конфиденциальность и безопасность**. Сборка пока распространяется без нотарификации Apple.

Langg работает в строке меню. Проверить и установить обновление можно в настройках приложения, в разделе **О приложении**.

## Возможности

- Автоматическое исправление раскладки между русским и английским.
- Исправление слова или выделенного текста, переключение раскладки и отмена по настраиваемым сочетаниям.
- Исключения для отдельных слов и приложений.
- Адаптация к ручным исправлениям и отменам (beta).
- Индикатор текущей раскладки в строке меню и уведомления рядом с курсором.

## Приватность

Langg обрабатывает текст на Mac. Решения адаптации хранятся локально, без истории набора. Приложение обращается к GitHub для проверки и загрузки подписанных обновлений.

## Разработка

<details>
<summary>Сборка из исходников</summary>

Нужны macOS, Xcode и Swift 6. Запустите сборку из корня репозитория.

```sh
swift build
```

Команда собирает исполняемый файл. Для запуска из Finder нужен пакет `.app` с ресурсами из `Resources` и фреймворком [Sparkle](https://sparkle-project.org/).

</details>

# Langg

Бесплатная утилита для macOS, которая исправляет текст, набранный в другой раскладке. Например, `ghbdtn` превращается в `привет`, а `руддщ` в `hello`.

Langg работает в строке меню, помогает во время печати и не требует подписки. Проект будет развиваться и получать новые версии.

## Возможности

- Автоматическое исправление завершённых слов с проверкой системным словарём.
- Исправление слова под курсором или выделенного текста по горячей клавише.
- Переключение русской и английской раскладок, включая сочетания только из модификаторов.
- Отмена исправления с восстановлением раскладки по желанию пользователя.
- Исключения для приложений и слов.
- Небольшое уведомление рядом с исправленным текстом.
- Запуск при входе и системное светлое или тёмное оформление.
- Проверка, загрузка и установка подписанных обновлений из GitHub внутри приложения.

## Установка

Требуется macOS 14 или новее. Поддерживаются Apple Silicon и Intel.

1. Скачайте `Langg-…-macOS.dmg` из [Releases](https://github.com/frlvv/Langg/releases) и откройте его.
2. Перетащите Langg в папку Applications внутри образа, затем извлеките образ в Finder.
3. Откройте Langg и выдайте запрошенные разрешения в настройках macOS.
4. Добавьте стандартные раскладки «Русская» и «ABC» или «США».

Сборка пока распространяется без сертификата Developer ID и нотарификации Apple. При первом запуске macOS может попросить отдельно подтвердить открытие в разделе «Конфиденциальность и безопасность». Не отключайте системную защиту целиком. Последующие обновления проверяются по Ed25519-подписи.

В образе также есть краткая инструкция `Установка.txt`. ZIP приложения нужен для встроенных обновлений, а архив `source.zip` предназначен для разработчиков. Для обычной установки достаточно DMG.

«Универсальный доступ» нужен для чтения выделения и замены текста, «Мониторинг ввода» – для обработки клавиатуры. Оба шага показаны при настройке. Управление и отзыв разрешений доступны в настройках приложения.

После включения мониторинга ввода macOS обычно предлагает завершить и снова открыть Langg. Подтвердите системный перезапуск. Если предложение не появилось, резервный перезапуск доступен в разделе «Доступ всё ещё не работает?». Перезагрузка Mac не нужна.

## Управление

| Действие | По умолчанию |
| --- | --- |
| Исправить слово или выделение | `⌃⌥Пробел` |
| Переключить раскладку | `⌘⇧`, после отпускания клавиш |
| Отменить исправление | `⌘Z` |

Сочетания можно изменить. Если у Langg нет подходящего исправления для отмены, `⌘Z` продолжает работать в текущем приложении. Возврат раскладки при отмене включается отдельно.

## Как работает исправление

Langg проверяет завершённое слово и предлагает замену только при достаточной уверенности. Короткие сокращения, правильные слова, адреса, команды и смешанный текст могут остаться без изменения. Для неоднозначного текста используйте ручное исправление.

Совместимость зависит от поддержки текстового поля в macOS Accessibility. Защищённый ввод и пароли не обрабатываются. Терминалы исключены из автоматического режима по умолчанию.

Текст обрабатывается на Mac и не отправляется на сервер. Langg не сохраняет историю нажатий и введённого текста. Для обновлений приложение обращается к GitHub; системный профиль не отправляется. Обновления проверяются в фоне, а установка начинается по кнопке пользователя.

Если поле не поддерживает прямую замену через Accessibility, Langg временно использует локальный буфер обмена для вставки исправленного текста. После операции прежнее содержимое восстанавливается, если буфер за это время не изменился. Новые скопированные пользователем данные не перезаписываются.

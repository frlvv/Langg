Langg – установка

1. Перетащите Langg в папку Applications рядом с ним.
2. Извлеките образ Langg в Finder.
3. Запустите Langg из папки «Программы».
4. Выдайте разрешения, которые предложит приложение.

Langg работает в строке меню в верхней части экрана. Нажмите на его
значок, чтобы открыть настройки. Нужна macOS 14 или новее;
поддерживаются Mac с Apple Silicon и Intel.

Первый запуск

Эта сборка пока не имеет сертификата Developer ID и нотарификации
Apple, поэтому macOS может заблокировать первый запуск. После попытки
открыть приложение перейдите в «Системные настройки» →
«Конфиденциальность и безопасность» и подтвердите открытие Langg.
Открывайте приложение, только если скачали его из официального
репозитория. Отключать защиту macOS целиком не нужно.

Разрешения

«Универсальный доступ» нужен для чтения выделения и замены текста.
«Мониторинг ввода» позволяет получать нажатия для автоисправления.
Текст обрабатывается на вашем Mac; история нажатий не сохраняется.
Если macOS предложит завершить и снова открыть Langg после выдачи
доступа, подтвердите перезапуск приложения.

Обновления

Langg сообщает о новых версиях. Загрузка и установка запускаются
по кнопке внутри приложения, без браузера и повторного переноса
в Applications. Подлинность обновлений проверяется по подписи.

Langg бесплатен и будет получать обновления.
Описание, исходники и новые версии: https://github.com/frlvv/Langg

# Сборка и выпуск

Нужны macOS, Xcode и Swift 6. Зависимости зафиксированы в `Package.resolved`.

```sh
swift test --build-system native --sdk "$(xcrun --sdk macosx --show-sdk-path)"
bash scripts/build-app.sh
```

По умолчанию приложение устанавливается в `/Applications/Langg.app`. Перед заменой работающей копии завершите её. Для другого пути передайте его первым аргументом. `LANGG_BUILD_ARCHS="arm64 x86_64"` создаёт универсальную сборку.

Локальная сборка использует постоянный сертификат в пользовательской связке ключей. Он сохраняет идентичность между версиями, но не подтверждает разработчика у Apple. При смене сертификата macOS может потребовать повторно выдать разрешения.

## Публичный выпуск

Публичная сборка без Developer ID возможна, но первый запуск потребует подтверждения macOS. Используйте один и тот же локальный сертификат для всех версий и обязательно подписывайте архивы Sparkle. Для установки без предупреждений Gatekeeper нужны сертификат Developer ID Application и нотарификация Apple. Передайте сертификат через `LANGG_SIGNING_IDENTITY`. Закрытые ключи и пароли должны храниться вне репозитория.

1. Обновите `CFBundleShortVersionString` и увеличьте `CFBundleVersion` в `Resources/Info.plist`.
2. Соберите универсальное приложение с постоянным сертификатом. Если есть Developer ID, укажите его через `LANGG_SIGNING_IDENTITY`.
3. Запустите `scripts/prepare-release.sh` с путём к приложению и номером версии. Для выпуска без нотарификации задайте `LANGG_ALLOW_UNNOTARIZED=1`. Для нотарификации задайте `LANGG_NOTARY_PROFILE`, созданный командой `xcrun notarytool store-credentials`.
4. Загрузите подготовленные DMG, ZIP, `SHA256SUMS` и `appcast.xml` в GitHub Release с тегом `v<версия>`.

DMG предназначен для первой установки: внутри находятся Langg, ссылка на Applications и инструкция. ZIP приложения используется Sparkle для встроенных обновлений. Архив `source.zip` содержит только публичные исходники и документацию.

Чтобы создать только установочный образ из готовой сборки, без повторного обращения к ключу обновлений:

```sh
bash scripts/create-dmg.sh /path/to/Langg.app 0.2.0 /path/to/Langg-0.2.0-macOS.dmg
```

Поток обновлений: `https://github.com/frlvv/Langg/releases/latest/download/appcast.xml`. При переносе репозитория измените `SUFeedURL` до выпуска первой сборки.

## Подпись обновлений

Sparkle проверяет Ed25519-подпись архива до распаковки. `SUPublicEDKey` содержит открытый ключ. Закрытый ключ не включается в приложение или исходники.

Инструменты Sparkle находятся в каталоге `artifacts/sparkle/Sparkle/bin` выбранного SwiftPM scratch-каталога. Создайте собственный ключ командой `generate_keys --account app.langg.Langg` и замените открытый ключ в `Info.plist`, если выпускаете собственную сборку. Скрипт выпуска по умолчанию использует этот аккаунт Keychain. Для CI можно передать файл закрытого ключа через `LANGG_SPARKLE_KEY_FILE`; файл должен быть создан из секрета CI и удалён после сборки.

При подготовке выпуска macOS может запросить доступ `generate_appcast` к записи «Private key for signing Sparkle updates» в связке ключей. Это доступ инструмента разработчика к ключу подписи, а не запрос установленного Langg. Разовое разрешение может понадобиться снова при следующем запуске инструмента. Пользователям закрытый ключ не передаётся; при установке и обновлении приложения этот запрос не появляется.

GitHub Actions проверяет исходники и тесты. Скрипт выпуска создаёт артефакты для GitHub Release; автоматическая публикация отключена. Для выпуска с нотарификацией нужны сертификат Developer ID, данные нотарификации и Ed25519-ключ. Для сборки без нотарификации достаточно постоянного сертификата и Ed25519-ключа.
